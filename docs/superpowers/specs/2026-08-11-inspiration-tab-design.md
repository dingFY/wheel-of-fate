# 灵感 Tab 设计

## 目标

为“转盘决定局”增加一个无需后端的模板广场，帮助用户从场景化模板直接进入现有转盘玩法。

## 导航与页面

底部导航调整为“首页｜灵感｜我的”。灵感页默认展示热门推荐，并提供关键词搜索以及“全部、聚会、情侣、吃喝、周末、挑战、破冰”分类筛选。

模板卡片展示图标、名称、简介、选项数量、分类和可选热度标签。点击卡片直接进入玩法页，不增加模板详情页。卡片提供独立收藏按钮，收藏状态保存在本机 `templateFavorites` 中。

## 数据与跳转

内置模板集中维护在 `data/templates.js`。每个模板包含 `id`、`name`、`icon`、`category`、`desc`、`tag`、`mode` 和 `options`。

灵感页通过 `/pages/play/play?templateId=<id>` 跳转。玩法页按模板 ID 加载模板，将字符串选项转换为现有转盘选项结构，并沿用增删选项、抽取结果、保存常用转盘和历史记录功能。

## 首批内容

首批提供 18 个模板，每个分类 3 个，覆盖聚会、情侣、吃喝、周末、挑战和破冰场景。数据全部随小程序发布，不使用云开发或外部接口。

## 边界行为

搜索同时匹配模板名称和简介，搜索无结果时展示空状态。未知模板 ID 回退到普通默认玩法，避免页面无法使用。收藏只保存在当前设备。
