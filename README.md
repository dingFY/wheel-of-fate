﻿﻿﻿# 转盘部落

一个零后端、零付费接口的原生微信小程序，帮你解决"今天去哪、干啥、吃什么"的选择困难症。

## 功能

- **随机转盘**：多种转盘模式，快速随机出结果
- **命运剧本**：根据同行人、心情、时间自动生成一套日常活动方案，包含活动、美食、小任务
- **一键随机**：不想填参数就点"随机帮我决定"，秒出剧本
- **换一个**：不满意立刻重抽，保持当前参数重新生成
- **存图分享**：生成剧本图片保存到相册
- **历史剧本**：已接受的剧本自动保存，随时回顾
- **常用转盘**：保存常用转盘配置，下次直接用
- **提意见**：一键唤起微信客服，直接反馈

## 页面结构

- `pages/play/play`：转盘首页
- `pages/inspiration/inspiration`：命运剧本生成页
- `pages/profile/profile`：我的（历史记录、常用转盘、更多）
- `data/fate-story.js`：剧本词库与生成逻辑

## 本地运行

1. 打开微信开发者工具
2. 选择"导入项目"
3. 项目目录选择本仓库根目录
4. AppID 填写自己的小程序 AppID 或使用测试号

## 数据说明

所有数据存储在用户本地（`wx.setStorageSync`），不上传任何服务器，换设备后数据不互通。

- `fateStoryHistory`：历史剧本记录
- `savedWheels`：常用转盘配置
- `wheelHistory`：转盘使用记录
