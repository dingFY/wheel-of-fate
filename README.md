# 谁来买单小程序

一个零后端、零付费接口的原生微信小程序小游戏，随机决定这一餐由谁买单。

## 功能

- 添加参与者和头像
- 随机抽取付款人
- 本地保存参与者名单
- 本地保存付款历史
- 玩法说明和趣味文案

## 页面

- `pages/home/home`：抽签首页
- `pages/history/history`：付款记录
- `pages/profile/profile`：玩法说明

## 使用方式

- 打开微信开发者工具
- 选择“导入项目”
- 项目目录选择：`E:\develop\上班族快手菜小程序`
- AppID 可选择测试号或使用 `touristappid` 体验

## 后续可扩展

- 增加更多本地菜谱数据
- 替换真实菜品图片
- 增加厨房技巧、热量筛选、难度筛选
- 后期接入小程序流量主广告变现

## 本地菜谱库

- `billParticipants`：本地参与者
- `billHistory`：本地付款记录
